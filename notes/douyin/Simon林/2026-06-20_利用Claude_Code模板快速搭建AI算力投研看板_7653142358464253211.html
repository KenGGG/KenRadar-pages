一、内容简述

（一）一句话结论

一句话结论 · 内容来源的摘要 视频演示了如何复用之前为人形机器人搭建的投研看板模板，通过零代码基础的Claude Code工具，快速构建针对AI算力产业链的分析框架。主要步骤包括复制提示词让AI读取现有结构并新建独立板块，随后批量拉取行业研报并自动填充各环节的定位、价值量、壁垒等关键信息。该方法强调通用性，适用于任何产业链的快速研究搭建。

（二）核心内容

  1. 核心逻辑：模板复用与产业链通用性 视频指出，搭建投研看板的核心在于方法论的通用性。无论分析哪条产业链（如人形机器人或AI算力），基本逻辑一致：先梳理产业链环节构成，再沿链条寻找价值量大、壁垒高、具备国产替代潜力的环节。因此，之前搭建好的“人形机器人”板块可以作为一个可复用的模板，直接照搬到新的赛道上。

  2. 第一步：搭建框架与初始化结构 操作方法是复制特定提示词给Claude Code，指令其读取项目中现成的“人形机器人”板块结构，并据此新建一个独立的“AI算力”板块。执行后，侧栏会迅速生成一条结构与原模板完全一致的AI算力栏目。初始结构包含八个环节，并预留了需求端（如计算中心）等泛指说法，每个环节下预设了空白的研究模板字段，包括环节定位、竞争格局、壁垒、类型及评分维度。

  3. 第二步：填充研报与细化产业数据 通过两行提示词完成数据填充。首先，指示AI按行业拉取一批AI算力的研究报告并归档至研报库，形成清晰的列表（含日期、机构、标题、所属环节）。其次，让AI阅读这些研报，将产业级的详细内容填入对应的环节模块中，包括环节定位、价值量、国产化程度、壁垒类型等。更深层次的竞争格局和细节暂时留白，以便后续逐步补充。

  4. 异常处理与推广建议 如果在自动化过程中遇到报错，视频提供了“万能套路”：将报错的原样文本复制并发送给AI，附加一句“这里报错了，帮忙解决一下”，让AI自行修复。最后，作者表示这套方法同样适用于其他方向，并邀请观众在评论区留言指定下一个想要研究的赛道。

1. 引言与核心方法论

呃，零代码基础也能用Claude Code搭一个属于自己的A股投研看板，这一集换条赛道照搬就行。之前给人形机器人搭好的那一栏，其实是一套能反复用的模板。第一集就把它照搬一遍，当场在侧栏多出一条结构完整、研报也填好的AI算力。为什么能照搬？因为看任何一条产业链都是同一套看法，先看这条链由哪些环节构成，再沿着链去找价值量大、壁垒高、国产替代的那个环节。方法不变，换的只是环节名。

2. 第一步：加栏套模板

第一步，加栏套模板，把屏幕上这段话复制过去，核心就一句，让它先去读项目里现成的人形机器人板块，照着同样的结构，新建独立的一条AI算力，别动。原来的人形机器人几秒钟侧栏就多出一条AI算力，结构和人形机器人一模一样。需求端用计算中心这种泛指的说法，八个环节，一字排开，数据先留个白点。进任意一个环节，都是同一套研究模板：环节定位、竞争格局、壁垒、类型、评分维度，先是一个个空框，下一步就来填。

3. 第二步：拉研报填满

第二步，拉研报填满，把屏幕上这两句复制过去。第一句，让他按行业拉一批AI算力的研究报告归到研报库。第二句，让他读完研报，把每个环节、产业级的内容填上，更深的细节先留着，慢慢补。一批行业研报，真实拉取，自动归成一栏，日期、机构、标题、所属环节清清楚楚，一目了然。产业级的内容也填满了，环节定位、价值量、国产化、壁垒、类型，一格一格补齐。更深的竞争格局和细节，留着接着往下做。

4. 异常处理与总结

卡住，别慌，万能套路。只有一个哪里报错，就把那段原样复制丢回去，加一句“这里报错了，帮忙解决一下”，剩下的交给他自己排。一套模板搭好之后，换条赛道，几句话就照搬出来了。同样这套招，换成别的方向，也一样能再来一遍。下一条，我想看哪个，评论区留言。
