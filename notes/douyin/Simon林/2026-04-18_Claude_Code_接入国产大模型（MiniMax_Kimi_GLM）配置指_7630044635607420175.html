一、内容简述

（一）一句话结论

一句话结论 · 内容来源的摘要 针对 Anthropic Claude Code 订阅费用高及支付难的问题，介绍通过修改环境变量（ENV）将后端切换至 MiniMax、Kimi 或智谱等国产大模型的方法。该方法无需安装额外代理或本地服务，利用 MiniMax 对 Anthropic API 的兼容性实现低成本调用，同时保留原有 Agent 和 Skill 功能，支持多模型并存。

（二）核心内容

  1. 背景与解决方案概述 为解决 Claude Code 订阅昂贵（约200美元/月）及支付困难问题，提出通过修改环境变量将后端切换至国产模型（如 MiniMax、Kimi K2.5、智谱 GLM-4.7）。该方法零依赖，无需 Router 代理或本地服务，仅需修改 ENV 文件即可实现，成本可降至约 200 元人民币/月。

  2. 技术原理与兼容性 利用 MiniMax 提供的接口 100% 兼容 Anthropic 接口的特性，伪装成 Anthropic API。Claude Code 调用时无法区分，实际请求由 MiniMax 处理。原有的 Agent、Skill 等功能均可正常使用，无需重新配置。

  3. 具体配置步骤

    1. 打开 Claude Code 设置界面（Settings/Suggestions）。2. 找到 ENV 模块并粘贴 MiniMax 提供的配置信息（包括兼容 Anthropic 的地址、API Key、默认模型如 M2.7）。3. 重启 Claude Code 使配置生效。

  4. 使用场景与注意事项 配置后，命令行（VS Code 或 CLI）接入将使用国产模型（如 MiniMax M2.7），而通过 Anthropic 官网打开的桌面客户端仍可使用原模型（如 Opus 4.7），两者可在同一电脑并存。若配置复杂，可将截图发给 AI 辅助配置，或搜索 GitHub 上的相关插件。

二、分段原文

以下内容保持博主原意和论述顺序，仅修正明显错别字、ASR 识别错误、标点与断句。

1. 引言与痛点分析

大家好，今天给大家分享 Claude Code 如何接入国产大模型。前几期给大家做完之后，很多朋友在评论区留言说这个 Anthropic 的 Claude 太贵了，还有很多搞不定订阅。所以今天我就直接分享如何接入国产大模型来解决这个问题。

2. 核心方法与优势

Claude Code 通过本地安装之后，通过 ENV 的切换是能直接将 Opus 4.7 直接切换到 MiniMax、智谱、Kimi。基本上就是 200 美元每个月很容易就变成了 200 人民币每个月。这个是怎么实现的呢？其实我们是通过 CC 自带的切换后端的能力来实现的。首先这个方法它是零依赖的，不需要装任何东西，不需要 Router 代理，也不需要本地服务，改个 ENV 的文件就可以了。

3. 技术原理：API 兼容性

第二呢是直连 MiniMax，我是用 MiniMax 所以这里讲一下 MiniMax，就是 MiniMax 伪装成 Anthropic。所以我们本地的 Claude Code 去调用 API 的时候，它会以为它是调用的准确的 API，实际上是调用的 MiniMax。因为 MiniMax 提供了一模一样的接口，CC 是完全分不出来的。第三呢就是 Agent、Skill 其实都是照用的，就是之前我们装的 ECC 全部都能保留都能正常使用。

4. ENV 概念与配置操作

那 ENV 是什么？ENV 它就是一个环境变量，英文是 environment，听起来很专业，其实它比较简单就是告诉 Claude Code 你要去哪接入。安装也比较，就是调试安装也比较简单，就是你就打开这个 Claude Code 的 setting suggestions，然后把 env 的这个模块给它粘进去就可以了。然后这一页呢我就贴的是这个 MiniMax 的 env 给大家讲一下，就是 MiniMax 官方的给 Claude Code 专门留了一个入口，是 100% 兼容 Anthropic 的接口的，就是第一行的这个地址。然后你再放入你的 API，然后还有默认的模型就可以了，现在最新是 M2.7，还是挺好用的。

5. 生效验证与多模型共存

你把这些都贴进去之后，再重新启动一下 Claude Code，然后就直接就可以调用了，就非常的丝滑，没有什么问题，不用装那么多复杂的东西。我们配置完之后，Claude Code 的模型就从 Opus 4.7 切换到了我们的国产模型了。然后我们的本地的这个命令行，你通过 VS Code 还是 CLI 直接接入，都是走的这个 MiniMax M2.7。然后呢你的桌面的客户端，在 Anthropic 官方网站上打开的这个桌面客户端，它还是会走 Opus 4.7。所以你的 Opus 4.7 跟 MiniMax M2.7 是可以在同一台电脑上并存的，我目前就是这么使用的。

6. 替代方案与结语

当然了如果说大家觉得这些东西还是相对复杂一点，你还有一种方法就是你把这个截图发给 AI，让他去给你配，你告诉他这些网址，然后包括你的 key，让他给你配，这个就 OK 了。然后如果说他还是搞不太懂，那你再让他去 GitHub 上去搜一些 CC 的插件吧，然后你再弄。但我觉得这个其实已经挺简单的。好了，这期就分享到这里，谢谢大家。
